# 復能計畫與執行檢核

給**日間照顧**與**住宿機構**用的簡易復能工具。機構原本已有管理系統，這個工具只做：

**評估 → 介入計畫（個別＋團體）→ 個別執行快速勾選 → 輸出列印**

1. **評估**：巴氏量表、體能與跌倒風險（TUG、30秒坐站、握力、單腳站、步速），IADL、SPMSQ 選填。系統依結果建議需復能的問題、個別項目、團體與輔具。
2. **介入計畫**
   - **個別介入**：運動、日常生活訓練（附圖片），設定劑量、執行日、每日次數、執行者。
   - **團體介入**：直接勾選運動、認知、懷舊、社交、手工藝、藝術、音樂、園藝團體（可自訂），填頻率即可，不需活動紀錄。
   - **建議評估輔具**：依評估自動帶入，連結長照輔具資料庫。
3. **今日勾選**：所有個案今天的個別項目一頁列出，點一下 ✓、再點 △、再點 ✕，也有「全部完成」。
4. **輸出**：Word（.docx）、PowerPoint（.pptx）、PDF（列印視窗選「另存為 PDF」）。

| 文件 | PDF | Word | PPT |
|---|:-:|:-:|:-:|
| 復能評估表（含空白版） | ✓ | ✓ | |
| 復能介入計畫書（個別項目附圖，PPT 為一項一頁衛教投影片） | ✓ | ✓ | ✓ |
| 個別執行檢核表：週表、月表、長輩自我檢核大字版（附圖）；空白或帶入紀錄 | ✓ | ✓ | |

## 資料來源
- 復能項目與圖片：[復健復能處方箋開立系統](https://mattsue1003.github.io/reablepre/)（127 項，圖片已壓縮存於 `assets/ex/`）
- 輔具說明：[長照輔具資料庫](https://mattsue1003.github.io/long-term-care-assistive-devices-database/)

## 使用方式
- 用 Chrome / Edge 開啟 `index.html`（需與 `assets/` 資料夾放在一起）。建議放 GitHub Pages 使用，Word／PPT 才能內嵌圖片。
- 第一次選擇機構類型（日間照顧／住宿機構）；住宿機構會多「房號／床號」並預設每天執行。
- 右上角填「記錄者」姓名。資料只存在這台電腦的瀏覽器，請到「設定與備份」定期匯出。

## 開發
原始碼在 `src/`，修改後執行 `python3 build.py` 產生 `index.html`。
`src/vendor/pptxgen.bundle.js` 為 PptxGenJS 4.0.1（含 JSZip，MIT License）。
