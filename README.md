# 復能計畫與執行檢核

給**日間照顧**與**住宿機構**用的簡易復能工具。機構原本已有管理系統，這個工具只專注在四件事：

1. **評估**：巴氏量表、體能與跌倒風險（TUG、30秒坐站、握力、單腳站、步速），IADL、SPMSQ 選填；系統建議需復能的問題與項目。
2. **開立計畫**：個別復能計畫（目標、項目、劑量、頻率、執行者）與團體復能計畫（成員、時間、活動流程）。
3. **執行檢核**：照服員或治療師在電腦/平板上勾選 ✓ △ ✕；團體每次記錄出席、參與程度、耐受度。
4. **輸出列印**：Word（.docx）、PowerPoint（.pptx）、PDF（列印視窗選「另存為 PDF」）。

## 使用方式
- 用 Chrome / Edge 開啟 `index.html`，單一檔案、離線可用。
- 第一次選擇機構類型（日間照顧／住宿機構），住宿機構會多「房號／床號」並預設每天執行。
- 右上角填「記錄者」姓名，勾選紀錄會留下記錄者。
- 資料只存在這台電腦的瀏覽器，請到「設定與備份」定期匯出。

## 開發
原始碼在 `src/`，修改後執行 `python3 build.py` 產生 `index.html`。
`src/vendor/pptxgen.bundle.js` 為 PptxGenJS 4.0.1（含 JSZip，MIT License）。
